## Project Brief

Local-first Agent Coach experience dashboard. Quiet dark operational console, readable and trustworthy. Sidebar: Overview, Experience, Coaching Traces, Evolution Queue, Integrations. First viewport prioritizes current learning health, latest coaching trace, accumulated knowledge by type, and three host connection states. Avoid fake business metrics, excessive cards, neon gradients, and marketing copy. Desktop-first with a clean narrow responsive layout.

## Manager Delegation And Accepted Concept

The manager explicitly delegated UI direction and product-design decisions for this unattended build. The team compared five catalog directions and selected Operational SaaS Console as the best fit. The generated complete-screen concept is the accepted implementation reference:

This delegation satisfies the direction-selection and draft-confirmation gate for this run. It does not weaken browser fidelity QA: the implemented dashboard must still be compared directly with the concept before handoff.

## Information Architecture

| Region | Required content |
|---|---|
| Sidebar | Overview, Experience, Candidate Review, Coaching Traces, Integrations, Privacy & Settings, Local only |
| Header | Current learning health and minimal utility actions |
| Latest coaching trace | Turn title, four lifecycle steps, before/after plan delta, full-trace action |
| Accumulated experience | Preference, knowledge, experience, and procedure counts plus seven-day growth |
| Evolution queue | Type, title, source, confidence/evidence, and Review action |
| Integration rail | Codex, Kimi Code, DSH, memory-provider health, and candidate-review action |

## Implementation Inventory

- React + Vite app shell with small feature components rather than one monolithic component.
- Code-native text, tables, status indicators, charts, buttons, filters, dialogs, and responsive navigation.
- True near-black canvas, restrained violet accent, thin borders, compact controls, and open table/rail layouts.
- No raster asset is required in the running UI; the concept image is QA evidence only.
- Core interactions: navigation, filters, trace selection, candidate review/approve/reject, integration detail, privacy/lifecycle settings, and live refresh.
- Narrow layout: sidebar collapses to a horizontal or drawer navigation; the integration rail moves below the primary workflow without losing actions.

The generated concept predates the final privacy-contract review. The implementation intentionally adds one `Privacy & Settings` navigation row and names the queue destination `Candidate Review`; no other first-viewport composition change is authorized by this adjustment.
